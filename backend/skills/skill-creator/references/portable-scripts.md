# 可移植辅助脚本

仅为能节省重复实现的计算、转换或验收逻辑生成脚本。无需脚本时将方法与验收契约写清即可。

实现参考必须来自宿主核验的成功程序记录，包含相符的源码版本；普通工具文本自报“成功”不足以授权。参考会移除私有字面量、内嵌数据与注释，只能用于理解计算结构，不能直接执行。依据完整方法契约重新绑定字段、参数和输出，保留已成功实现的方法细节及可用依赖。历史源码证据不可用时，明确将新脚本标记为重新实现，不能声称复制了原成功程序。

将完整工作流与脚本分别生成。文件路径、用途、参数调用来自已经确认的实现计划，脚本阶段只编写完整 Python 文件正文，不将长源码嵌入 JSON 字符串，也不重复生成文件元信息；篇幅不构成删掉实现、用 TODO/pass 或虚构数值代替计算的理由。脚本实际实现的每项要求必须有可追溯覆盖关系，不能仅在注释中列出方法名称。

- 使用 `scripts/<action>.py`，公开调用提供 `--input` 和 `--output`，可使用任意参数解析库。数据字段、范围或方法参数按需要增加显式参数。
- `--input` 的文件格式、多输入角色映射及字段映射必须明确；`--output` 的文件或目录类型、产物文件名和字段必须在帮助与输出契约中一致。示例只使用参数占位符，不保留原附件名或当前会话路径。
- 新设计需要多个文件时，`--input` 指向单个 JSON 输入清单，由任务公开契约定义文件角色，角色值绑定本次明确授权的文件路径。清单仅绑定文件，不改变来源数据字段、配置位置或方法参数的含义；不强制固定角色键名。合成用例可在清单中使用完整的 `{input:name}` 字符串，由宿主递归绑定已声明输入；不要拼成 `role={input:name}`，也不要重复 `--input`。已有明确的调用契约不强制迁移；当前验证环境不能支持时如实说明。
- 校验路径参数指向不同位置，保留输入只读；输出父目录由当前任务授权并显式选择。不得通过硬编码路径寻找历史文件。
- 合成验收可检查“输入输出同址时明确拒绝”：仅当用例为 `invalid`、预期正常非零退出时，让 `--input` 与 `--output` 都使用同一已声明输入文件的完整占位符。可追加 `output_empty` 或 `stderr_contains` 拒绝后置条件，分别观察独立输出目录为空和拒绝诊断，不读取输入为产物，也不检查科学输出值。输入仍只读并核对哈希不变；不得改用另一份输入、真实路径或允许写入。普通成功、边界用例及科学产物断言仍必须使用独立输出位置。
- 不包含重放历史命令、读取历史凭证或未经授权发布的步骤。所有库和 API 均可使用，包括动态导入、特殊方法和子进程；不按操作或 API 名称设置名单。可在任务隔离环境准备所需依赖，文件操作与网络调用须符合当前授权、输入只读和独立输出边界。
- 不设依赖库名、导入、模块导出或 API 的白名单与黑名单；可声明并导入适合任务的标准库或第三方库。优先使用现成库完成解析、压缩、图像与表格处理，不手写替代实现来绕过环境策略。声明依赖、版本约束和运行前可用性检查；允许导入不代表当前环境已安装，缺少依赖时可先准备隔离环境；无网络或其他环境原因导致无法安装时明确报告，不能假称执行成功。命令行帮助应能说明输入契约和产出。
- 采用明确异常和退出状态，拒绝不满足契约的输入；不静默填充会改变科学结论的默认值。
- 来源只规定拒绝而没有精确退出码时，合成计划使用 `expected_exit_code: "nonzero"`，不猜测具体为 1 还是 2。正常的输入拒绝、解释器故障、超时与信号终止必须区分；不能把脚本出错当作完成输入校验。
- 可按职责拆分读取、计算与写入辅助函数；不要求特定解析器、单个路径保护条件或读写集中在主入口。异常信息可说明缺少哪个方法字段、哪项条件不满足，不输出原始数据行、访问令牌或历史路径。
- 新增脚本先通过 Python 语法编译与公开调用 token 检查；静态通过不证明依赖已安装、输入未修改、输出隔离或程序执行成功。支持的 CSV/JSON 流程还在无网络隔离环境运行正常、边界与无效合成用例。预期值由独立请求根据原方法要求推导，宿主逐项核对真实文件，失败时只修脚本，不修改冻结预期。用例不可用或不适用时不得声明运行通过。首次使用仍要核对版本、适用性和当前输入；合成验证不等于实际数据分析完成。

新创建先声明版本化脚本接口，再生成代码。CLI、输入结构与配置位置、输出文件及公共字段、缺失与拒绝语义在生成前冻结；候选、独立参考与用例设计使用同一声明。语法分析只核对可证明的接口矛盾，不推断科学答案或禁止未知库/API。历史源码中的方法常量只有来源支持且通过隐私检查才保留；私有成员占位与历史版本关系不表示该程序可以直接执行或已经被最终采用。
